# MySim Racing

Godot 4.7 (C#) racing game. PC and Android, peer-to-peer multiplayer.

## Tracks
Circuit layouts are built from OpenStreetMap data with `tools/osm_track.py`.
Track data © OpenStreetMap contributors, available under the Open Database License (ODbL).

## Preview renders
`render` workflow: builds the project and saves preview shots as a run artifact.
